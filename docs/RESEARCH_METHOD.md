# Questions before conclusions

A useful taxonomy helps distinguish explanations. It should not turn a suggestive phrase into proof of a mechanism.

| Question | Why it changes the interpretation |
| --- | --- |
| What was sampled? | A collection of submitted cases can differ from all work attempted. A complete export is not necessarily a complete experiment. |
| What is the independent unit? | A later submission can include an earlier conversation. Counting both as independent observations repeats evidence. |
| Which input could the operator change? | A user-role message can be part of a scripted scaffold. The editable surface can be elsewhere. |
| What was actually observed? | Generated text, a recorded call, a tool return, and a verified state change support different claims. |
| What did the judge evaluate? | Final-response and whole-history scoring can behave differently as a conversation grows. |
| When was feedback available? | A message after submission does not establish that the operator had seen the judgment. |
| Who supplied the purported artifact? | A plausible reconstruction is not an authenticated copy of hidden material. |
| What did the assistant contribute? | Missing collaboration logs prevent reliable attribution of ideas or a causal estimate of assistance. |

For each claim, preserve the source, the observation, the inference, and what could falsify it. Record plausible alternatives before selecting a mechanism label. When cases share prompts, snapshots, operators, or hidden conditions, say how the dependency affects the conclusion.

Compare like with like before reporting rates or transfer. State the denominator, stopping rule, selection process, scoring scope, task, model configuration, and uncertainty. If these are unavailable, report the supported counts and their limits instead of a misleading success rate.

Reading paths and catalog links are educational relationships. They are not an ordering of likely effectiveness. A newly named combination needs evidence that it explains something existing concepts do not already explain.
